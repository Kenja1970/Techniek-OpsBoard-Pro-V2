# Claim Verification - Techniek OpsBoard Pro V2

This variant is positioned as a native Techniek project execution control center. It does not depend on an external task-board service for WBS, Kanban, Gantt, resource, financial, risk, issue, change, decision, or reporting workflows.

## Verified In QA

- WBS/CES import creates hierarchy, charge-task mapping, resource linkage, import history, and audit entries.
- Gantt rescheduling updates card dates and propagates into project/program schedule metrics.
- PMI EVM identities remain independently re-derived from raw workspace data.
- Contribution margin %, A/E multiplier, target CM coloring, FV/EAC history, and program rollups remain verified.
- Issues, decisions, programs, portfolios, integration settings, and audit trail are present in schema 3.0.0.
- Resource engagement planning rolls up weekly, monthly, yearly, and weekly-equivalent hours.

## Production Caveat

API endpoint and key fields are local placeholders only. Production credentials must be stored server-side after backend and security review.
