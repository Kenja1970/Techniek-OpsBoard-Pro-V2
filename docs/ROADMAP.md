# Roadmap - Techniek OpsBoard Pro V2

## Implemented MVP

- Native project workspace with WBS/Kanban, Gantt, resources, financials, governance registers, FV/EAC, audit, and reports.
- CES/P6 WBS CSV import and project package export APIs.
- Unanet/ERMAS-ready local data fields and backend/API placeholder settings.
- Resource types and weekly/monthly/yearly engagement rollups.

## Next Backlog

- Server persistence, enterprise authentication, encrypted storage, and server-side secret handling.
- Live Unanet, ERMAS, Microsoft Fabric/Dataverse, Power BI, SharePoint, and Teams adapters after security approval.
- Stronger dependency scheduling, baseline snapshots, and formal project package signing.
- Expanded report export formats and hosted PDF generation.
